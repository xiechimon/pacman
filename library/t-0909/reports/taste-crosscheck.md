# 参考站品味核对（#909）

参考产品 todos.dev 于 2026-10-05 匿名实测（scripts/taste-ref.mjs，playwright
computed-style 采样；截图 reference-todos-dev.png）。与仓内既有 live capture
（tokens.css 注释，2026-10-02/03：drag 投影、280px 列节距、drop tint、z 阶梯律）
互为印证，无漂移。

## 参考站实测 token

| 维度 | 实测值 |
| --- | --- |
| 画布（暗） | `rgb(24,24,27)` = #18181b（中性 zinc，无色相） |
| 正文 | `rgb(250,250,249)`，Inter（含 metric-override fallback 栈） |
| 圆角档位 | 12 / 8 / 6 px 三档 |
| 投影 | 采样面全 none——层级靠灰度分层与发丝线，不靠扩散投影 |
| 按钮 | 透明底 + 灰字（#71717a / #d4d4d8）；唯一实底档 #1f1f23（surface 二档），6px 圆角 |
| 色相纪律 | chrome 零品牌色相；彩色只出现在状态语义 |

品味 DNA：**中性优先、发丝线承重、小圆角、无扩散投影、彩色=状态**。

## 三个候选方向的站位

| 方向 | 与参考站的距离 | 说明 |
| --- | --- | --- |
| A 石墨 | 最近（同族演进） | 中性骨架 + 发丝线 + 零扩散投影全继承；比参考更锐（4px 档）且把「chrome 零色相」推到极致——连品牌实底都归中性，彩色只剩五状态 |
| B 青墨 | 同族 + 一处偏离 | 纪律全继承（8px 档、卡级微影、灰度分层）；偏离点 = 给交互件一个品牌色相（teal），参考站 chrome 是无色相的 |
| C 纸兰 | 最远（换族） | 暖纸骨架 + 14px 圆角 + 分层软投影 + orchid 品牌——四项参考站纪律（中性/发丝/小圆角/无投影）全部反向；editorial/craft 气质，与参考站的 Linear 谱系分家 |

裁决提示：选 A/B = 留在参考站品味族内做演进；选 C = 有意识地换族（用户四项裁决
已授权「几何自由重设计 + 色相重选」，换族在授权范围内，但要知道这是换族）。
