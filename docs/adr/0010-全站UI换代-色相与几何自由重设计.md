## Problem Statement

至 2026-10-05 前，站点视觉的正典链是：spec/16「像素纪律」——逐域迁移是**纯结构**改动、零视觉重钉，per-face 规则仍是几何与配色的正本（#411 政策 4 + #435 值正本并流后的口径）；#813 刚按此把色面封版（V2 + Herdr 紫，对比度复测封版 + fixture 基线 sealed）。铺开进度：B1 弹层族、B2 热身 + resources 已落地，B3/B4 未开工，per-face CSS 8266 行在树，`components/ui/` 26 件已就位。

问题是：纯结构迁移的终点是**旧脸换骨架**——视觉天花板被像素纪律锁死在旧脸上，而 8266 行 per-face CSS 同时扮演着「正本」与「债」两个角色。色彩、几何、CSS 债三个面若分开动，各要一轮施工加一轮 e2e 重钉。用户 2026-10-05 四项裁决把目的地改掉：一次换代到位，色相连 Herdr 紫一起重选，几何不受现状冻结，per-face CSS 全迁 Tailwind 清零，执行由 #908 地图直接携带。

ADR 三条件全中（#911 票面认定）：**难以逆转** = 全站视觉推倒重钉（2190 钉点 / 101 spec）；**无上下文会惊讶** = 像素纪律上周还是正典，spec/16 与 #411/#421/#435/#813 多票引用它；**真取舍** = 纯结构迁移 vs 自由重设计，#909 三方向沙盒（A 石墨无彩 / B 青墨 / C 纸兰）是摆给用户的真实选项，用户实审后选 C。

| ID | 裁决 |

| **D5** | **收编 #910 钉扎口径五项裁定**（裁定正本 = #910 决议评论，本条为正典锚定）：**D5.1** 钉扎载体 = 语义优先两级制——#411「类名别名保留总律」**明文废止**（per-face 清零后无别名可保），data-slot 不作载体，testid 命名 kebab-case 语义名 + spec 一律 `getByTestId()`，不建全量注册表（清单正本 = 代码 grep），批次验收审新增 testid 是否本可用 role 表达；**D5.2** 重钉时序 = 随改——每施工批次同一 PR 内完成本域 spec locator 换载体 + 视觉基线重钉，否掉「先铺钩」，integration 四文件同律计入批次验收（F8）；**D5.3** 行为/视觉断言机械判定表——批次直接套用不逐文件人工裁，状态类断言归行为、载体改 `aria-*` / `data-state`；**D5.4** 探针工具面全盘继承 #411——`toHaveScreenshot` 维持 0 处，computed-style 探针 + `apps/web/e2e/png.ts` luma 探针两件窄口径不变，token 取值 hex/rgb 记法契约禁 oklch（c.css 实测天然兼容，F6）；**D5.5** 视觉重钉 = 探针 dump + 人审 diff——禁纯手工抄值（2190 处不现实）、禁纯自动直写（会把真回归一起重钉进基线），工具建设 = #921，归档进 e2e 工具面供封版票复用 |

| **D7** | **保留面**（本 ADR 不动）：**行为契约语义面**——e2e 行为断言语义一字不动，只换 locator（D5.3 判定表是机械边界）；**动效机制**——沿 ADR 0009 收敛面（shadcn / tw-animate-css 默认），只消费不重设计；**ADR 0008 定位两轴**——自用第一判据与语义轴对齐不受影响，「参考实现优先、不凭空造」纪律仅在本次换代的视觉面（色相/几何/投影）反向（F7），不得扩大解释到行为语义与产品形态；**后端 / daemon / server**——不动，除非某域暴露真实端点缺口（届时另开票，#908 Out of scope） |

理由一句话：纯结构迁移的终点是旧脸换骨架，色彩、几何、CSS 债分开动要三轮施工三轮重钉；四项裁决把三轮并一轮，代价是 2190 钉点与 8266 行 CSS 一次性重进——D5 的机械判定表与 dump 工具把这轮重进压成流水线，D6/D7 把推翻与保留的边界钉死防扩大解释。

## 术语

五项术语的定义正本随本 ADR 落仓（#910 决议 / #911 票面指定）：

- **语义优先两级制**：e2e 钉扎载体策略。一级 = role/label/text 语义 locator（`getByRole` 优先）——几何自由重设计下唯一跨结构稳定的锚；二级 = `data-testid` 仅补语义盲区（无 role 的容器、纯结构钩子——#411 实测 63 个零 CSS 规则纯测试钩子即此类，规模预期 <100 个而非 522 个类的 1:1 平移）；`data-slot` 属 shadcn 组件内部结构、随上游升级漂移，只许组件内部定位辅助，spec 不钉。
- **行为断言**：钉语义不变的断言——文本内容、元素计数、可见性、disabled/checked 状态、导航跳转、键盘交互序列。换代只换其 locator，断言语义一字不动。状态类（`.is-active` / `.selected` 这类语义类）断言归行为断言，载体改 `aria-*` / `data-state`（shadcn 自带约定）。
- **视觉断言**：钉视觉呈现数值的断言——`getComputedStyle` 值、`boundingBox` 几何、表现类 `toHaveClass`、颜色/圆角/间距/字号数值。换代时整条按新正典重写，数值从 #912 正本表 + c.css 定版色板取。
- **随改**：重钉时序策略——每个域施工批次在**同一个 PR 内**完成本域 spec 的 locator 换载体与视觉基线重钉；改写者面对新 DOM 终态一遍到位，不先铺钩（对着将死的旧 DOM 铺钩 = 改两遍）、不事后补钉，main 不红。
- **探针 dump**：视觉重钉机械做法——工具在 fixture 栈上跑，采集既有 spec 探针点（computed-style / boundingBox）实际值出 JSON，生成「旧基线值（从 spec 内联断言解析）→ 新实测值」对照表；**人审 diff** 区分预期漂移（新正典）与疑似回归，确认后批量改写 spec 内联值。工具建设 = #921。

## Premortem（假设已失败，三种最可能死因 + 护栏）

| 死因 | 护栏 |
|---|---|
| **换脸后悔**：全站翻成纸兰后，用户对某个面想要旧观感或 A/B 方向回来 | 值正本集中（#912 正本表 + c.css），单面回退 = 改 token 值，不是换机制；#909 三方向沙盒可复跑（gen-palettes.mjs），A/B 版色板与 c.css 同在 t-0909 分支，退役时点在各域吸收定版之后（#908 fog） |
