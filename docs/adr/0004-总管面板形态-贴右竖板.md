# ADR 0004 · 总管面板形态 = 贴右竖板（背离原站第 3 例）

> 状态：**superseded by ADR 0013**（2026-10-08，总管面板形态反转为悬浮窗；原裁决 2026-09-30）。本文件保留作考古正本：重开触发第一条「开态持久化」命中，#447 动机被同一用户反转。
> 来源：#447（triage 2026-09-29 用户反馈：面板不应悬浮，应平铺弹出）。
> 本面为**第三个自觉背离 todos.dev 原站**的 UI —— 原站面板是 418px 内缩悬浮卡（r5 抓拍实测）。首个背离见 ADR 0002，第二个见 ADR 0003。

## Problem Statement

总管面板是一张内缩的悬浮卡（`position:absolute`、top 42 / right 17 / bottom 16、宽 418、圆角 12、带投影），浮在内容之上。诉求：面板不应悬浮，应平铺弹出——成为布局里的一列，而不是一个浮层。

该几何是 1:1 复刻的实测值（F1/F2），故本面是一次自觉背离。

## Decision

| ID | 裁决 |
|---|---|
| **D1** | **形态唯一**：总管面板只有一种形态——**贴右竖板**（满高、贴死右缘、圆角归零、无投影）。悬浮卡形态删除；#146 的「全屏 / 退出全屏」钮与其形态切换契约一并作废（钮删除）。 |
| **D2** | **让位机制 = flexbox**（`flex:none` 固定宽的面板 + 兄弟列 `flex:1; min-width:0` 自动让位），照左栏与详情右栏两处先例（F5）。**不引入 CSS grid 框架，不新增宽度 token**（F6）。 |
| **D3** | **分隔手段 = 1px `--border-default` 缝线**（仓内既律 Hairlines Not Shadows，照 `.detail-right` 的 `border-left`）。无阴影之后不另立新分隔物。 |
| **D4** | **入场动画**：面板自身沿用 `translateX` 滑入（既有 `anim-drawer`）；**内容瞬时贴合，不做布局动画**。`prefers-reduced-motion` 降级照既有律。 |
| **D5** | **宽度钉死 418px**（上游实测值，F1/F2）。拖拽调宽 = 明确 out of scope，另票。 |
| **D6** | **适用壳 = 无右侧栏的四个**：board / pages / resources / secondary。board 的包含块是视口（F4），故须在其 shell 容器这个 flex 行内给面板一个 flex 项；其余三壳天然在 `*-main` 内。 |
| **D7** | **详情路由特例 = 顶掉右栏**：该路由有 488px 右栏，418 竖板无位（F7，294px 余量）。裁决为总管**占用右栏那个格位（互斥）**，中列宽度不变——今天那张 418 浮层本就压在那 488px 右栏上，故不算退步。 |
| **D8** | **看板护栏**：面板打开时给 `.board-column` 一个 min-width 保住信息密度，让位改走**横向滚动**；面板关着时行为一字不变。护栏值须施工期实测确定，不得照抄 F8 的推算。**（2026-10-03 由 #692 修订：开态限定的 240px 护栏升级为全天候单源 token `--board-col-min: 280px`——参考站 2026-10-03 live 实测的固定节距；滚动条从恒隐藏改回原生 auto（溢出必须有披露），静止 ≥1440 几何不变。见 board.css 单源规则。）** |
| **D9** | **开态不持久化**：刷新即关（维持现状 `chiefView` 默认 `'none'`）。持久化若将来要做，做法照 F9 的侧栏先例，另票。 |

## Premortem（假设已失败，三种最可能死因 + 护栏）

| 死因 | 护栏 |
|---|---|
| **看板被压死**：让掉 418px 后四列从 ~281px 掉到 ~176px（F8，[推算]），卡片挤成竖条——本方案最可能的死法 | D8 的 min-width + 内容区横向滚动；面板关着时逐值不变，故静止态 spec 全保 |
| **详情路由无位可站**：294px 余量，中列让位不成立 | D7 改占右栏格位；中列几何零改动，`detail-3pane` 的钉扎不必重写 |
| **让位变布局震荡**：内容重排是布局动画，与既有纯 transform 入场律冲突，易抖 | D4 内容瞬时贴合，只动面板 transform；`prefers-reduced-motion` 降级 |

## Consequences

- **正向**：面板获得稳定列位，不再覆盖内容；形态语言与左栏、详情右栏统一（同族 flexbox + 1px 缝）；形态切换分支（CSS 两态 + 局部 state + 一条 spec）整体消失，是净删代码。
- **负向**：看板与各壳内容区在面板打开时变窄（D8 的横向滚动是这个代价换来的）；详情路由多一条特例分支（面板挂载点与其他壳不同）；上游复刻保真度在一个已实测的几何值上让位。
- **与原站关系**：第三个自觉背离面；背离的是**面板作为浮层**这一形态，面板的内容与行为契约（线程切换、composer、Esc 分层、焦点入 composer）不变。
- **重开触发**：要做面板宽度可调或开态持久化；B4（shadcn 铺开 chief 域）迁移改变容器结构；上游 todos.dev 自身改了面板形态（1:1 复刻的地基变化）。
