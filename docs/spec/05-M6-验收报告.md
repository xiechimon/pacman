## 1. M5 汇合实现纪要

### 1.1 数据源缝（一个显示契约、两个数据源）

- 显示契约（`apps/web/src/fixtures/records.ts`）= 像素矩阵冻结的组件 props 面，**不动**；
  live 数据层（`apps/web/src/api/`）把 02 §6.2 wire record 投影成同一显示契约：
  - `client.ts` 同源 fetch（错误形状 `{error}` 单形状，04 §3）；
  - `hooks.ts` TanStack Query v5（01/S8 pin 5.103.1 新入 catalog）查询/变更面，
    失效重取为唯一 server-state 策略；
  - `sse.ts` 原生 EventSource 双通道（team stream → invalidateQueries 提示信号 =
    S8 canon；conversation stream → transcript live 面）；
  - `mappers.ts` wire→display 投影（transcript 组装/plan.md 段落化/unified diff
    行号展开/token 计数形/运行历史行/chief 流）；
  - `live-text.ts` text_delta 打字缓冲（useSyncExternalStore；终稿 message 行落库
    即清空收敛——02 §1.2 双保险的流侧半）。
- 模式闸门（`api/mode.ts`）：`?scenario=` 且 dev/parity build → fixture；其余一切
  （含生产 build 恒真）→ live。**票面「scenario 参数退役 dev-only」= 本闸门**，
  parity 矩阵与既有 reject-chain e2e 的 fixture 数据面零改动。
- 桌面通知 divergence 兑现（04 §5/A5）：SSE notification 事件 → `document.hidden`
  时页内 `new Notification()`；无 Web Push/VAPID（登记口径，不判负）。

### 1.2 server 补齐面（词表内 + [推断] 登记）

- **conversation stream**：`GET /api/conversations/{id}/stream`（词表内、此前未实现）。
  事件定型四件 = ping / message / text_delta / step（载荷 [推断]，shared
  `conversationStreamEventSchema` 单源，快照冻结；官方逐事件载荷未枚举——补采后
  回写 02 §11 收紧）。发布点：live 工具行（reportTool）、transcript 终稿
  （receiveUpload）、步状态（enqueue/claim/finish）、驳回用户行、合并行、🎉 行、
  chief 消息行。
- **daemon live 文本转发**：pi `text_delta` 250ms 窗口聚合 → `POST tool/{stepId}`
  第三形 `{kind:"transcript_delta",text}`（[设计] 登记 shared machine-wire.ts；
  13 端点词表路径不改形状）；服务端瞬态转发不落库，终稿经 upload-urls 兜底。
- **词表补齐 GET/POST 族**（02 §6.1 canonical、03 §5「M5 wire = 全端点」）：
  teams/{id}/machines · models · progress · skills/{sid}(+/file) · agents/{aid}/tasks、
  GET/POST /api/skills、whats-new、analytics/first-touch + /_mp/api/track（词表
  「可空实现」= 204 收下即弃）。preview-token 不实现 = 04 附录 B「在册不设计」
  （无 UI/wire 触点，触发条件未至）。
- **[推断] build 详情读面**（wire.test INFERRED_ROUTES 登记，路径 = builds/{id}/…
  REST 同族规则）：plans（版本集+内容，r5 §4 触点）· changes（conv 分支 vs 默认
  分支 unified diff，r7 27 触点）· usage（token 四维，r3 §3.8/r7 30 触点）。
  steps 读面行透出 journal 位 status/checkpointCommit（[设计]，zod strip 下
  stepRecordSchema 对拍不漂移）。
- **SPA 静态同源托管（02/A1）**：ctx.webDir → 非 API GET 静态文件/SPA 回退
  index.html；/api、/git、/_mp 未命中恒 404 JSON（错误形状对拍面不破）；路径逃逸
  拒绝；index no-cache + 资产 1h。E2E 与生产形态同构（同源 cookie/SSE 免代理）。
