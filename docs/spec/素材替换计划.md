## D1 · 产品定位与仓库可见性

**锁定。** 产品定位 = **本地自用**。域名候选**不适用**（无对外发布计划）。repo `xiechimon/pacman` 保持 **PUBLIC**（既成事实：2026-09-08 起公开，含原样素材与 r1-r7 研究证据），**不改名**——repo 名 = 产品名 = pacman，无对外困惑。

「本地自用」不改变已锁决议「先原样放 GitHub，之后替换」：公开的是**研究仓库**（复刻过程 + 证据 + spec），不是产品发布。D3 触发条件为休眠护栏，**定位改变（对外推广/生产部署）时自动生效**。

风险提示（记录在案，不设护栏）：`pacman` 与 Arch Linux 系统包管理器同名，executor 机器跑 Arch 会 PATH 撞车；本机 macOS 无此问题，本地自用场景够不着。npm 事实：`pacman`（0.15.0，静态站生成器）与 `pacman-cli`（1.1.4）均被占用——**无关**，包名槽为私包不发布（§2）。

## D3 · 替换时机触发条件

**锁定。** 双触发，无日历里程碑：

1. **主触发**：任何**对外推广**（发布产品、公开演示产品面、分发安装物）或**生产部署**之前，§3 清单全部替换完毕。
2. **兜底触发**：**收到 takedown / 侵权通知时**，立即执行替换（不等主触发）。

研究仓库本身的公开（D1）不构成触发——公开的是复刻过程与证据，非产品推广。纯研究公开期允许清单素材以「原样复刻」形态存在于产品代码（`apps/web`）中，此为已锁决议「先原样放 GitHub」的执行语义。

**移交**：替换执行开独立票（一次性批量，含 parity 重定基线，见 D5），不与功能票（web/#5x 线）穿插。

**触发记录（2026-09-23，#109）**：用户本机同时运行正版 todos.dev daemon——`~/.tds` 被正版占用（machine.json/token 不可覆写），复刻版默认状态目录同名冲突，无法同机并行；据此**提前执行替换相位**（不等主/兜底触发）。本批执行面 = §2 品牌槽正典全表 + 同槽延伸（localStorage 键族 / manifest 品牌槽 / sw.js 通知标题 / env 词表 / API key 前缀 / 界面品牌词 Todos→Pacman）+ parity 重定基线（基线切自渲染产物，原站截图按 D4(a) 留 `docs/research/assets/`）。**未执行面**（仍待独立替换票）：D5 图标换 lucide、D6 emoji 子集、D7 字体重托管、D8 `[p]` logo 与位图派生、§3.4 其余自写文案（landing/install/changelog 等）；manifest `related_applications` 仍指原站域（r1 冻结面，随 D8 批次处置，登记于 apps/web/test/pwa.test.ts gate 注释）。

## D4 · 证据/产品两分法

**锁定。**

- **(a) 研究证据 = 永久保留**：`docs/research/assets/` 下全部原站截图（r2 63 张 / r3 ~52 张 / r5b 15 张 / r7 54 张权威基线）、icons.json dump（r5/r6/r7）、r1 抓取的 CSS/manifest/llms.txt/i18n 四语对照文件——是 r1-r7 spec 册的引用锚点与 parity 门禁对拍基线，**不入替换清单、不删除**。
- **(b) 硬边界**：`apps/web` 产品面**禁止引用** `docs/research/assets/` 任何文件。产品内素材一律来自替换清单（§3）替换值。护栏：CI/lint 检查产品代码不 import/不路径引用 `docs/research/`；替换执行票 audit 一次。
  - 例外（既成事实，随替换执行票消解）：`scripts/generate-icons.mjs` 以 `docs/research/assets/r*/icons.json` 为**构建期输入**生成 `apps/web/src/icons/*.tsx`——生成产物进产品、原始 dump 不进运行时，D5 执行时改为 lucide 官方包源，该依赖自然消失。

## D5 · 图标：全换 lucide，禁止自绘

**锁定。** 替换触发时，`apps/web` 全部图标改为 **lucide 官方包**（ISC license；建议 `lucide-static` pin 版为生成源，或直依 `lucide-react`，集成形态归替换执行票）。**禁止自绘**任何图标。映射以**好看/语义贴合**为准，**不追求与原站 1:1 字形**。

来源核验事实（2026-09-22，16 图标抽样对照 lucide v0.105.0/v0.263.0/v0.427.0/0.445.0/1.47.0）：

- 原站图标 = **lucide 衍生，置信度 ~0.95**：12/16 与 lucide 某版本逐字节或属性级一致（含 `16.65`、`M9.09 9a3…`、`M6 5v11` 等 lucide 特有指纹，可排除纯 feather）；版本跨 v0.105→v0.427 分批拷贝。
- **5 个非 lucide 定制条目**（法律风险面，被本决策覆盖）：clock(定时)、key(密钥)、server(机器)、user(帐号)、任务徽章(dog-ear 方块+勾)。参考映射（可改判，以好看为准）：`clock` / `key` / `server` / `user` / `square-check-big`。
- 现存 `apps/web/src/icons/*.tsx`（generate-icons.mjs 产物）主体按 lucide ISC 衍生处理无碍；替换 = 换官方包源 + 上述定制项换 lucide 对应。

**连带**：图标区域 parity 对拍**不做逐像素豁免清单**——替换后按 lucide 现版字形走，偏差为预期且接受；替换执行票一次性重定基线（对原站截图）。
