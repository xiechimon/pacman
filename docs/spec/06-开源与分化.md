> 正典地位：本册 = pacman 从「todos.dev 1:1 复刻工程」转为「自主开源产品」的方向决议，
> 优先级高于 03 册的复刻构建顺序（03 册 M0–M6 已闭环，仅作历史档案）。
> 裁决来源：2026-09-25 grilling 三轮九问定案。

## 0. 决议一览

| # | 项 | 定案 |
|---|---|---|
| D1 | 定位 | 自主产品。叙事 = self-hosted, open-source agent workspace；平替起步，分化从真实使用涌现 |
| D2 | License | Apache-2.0 |
| D3 | 名称 | 保留 pacman；npm 发布 = `@xiechimon/pacman` scope；改名窗口保留 |
| D4 | 公开策略 | 仓保持 public；门面（W1）修好之前不主动宣传 |
| D5 | 工作模式 | 仓库 owner = 产品负责人（定方向、审 PR）；施工走 agent 车道 |

| D7 | 研究资产 | `docs/research/` 截图与全部 git 历史保持现状；免责声明常驻；素材核账仅约束产品内资产 |
| D8 | 鉴权 | 可选 token 鉴权（env 显式开启、默认关）+ `0.0.0.0` 裸绑启动 WARN |
| D9 | 节奏 | W1 门面+鉴权 → W2 npm 首发 → W3 steer 中断 → W4+ 后票涌现制 |

## 1. D1 定位与对既有册的影响

- 复刻对拍义务自本册起解除：02/04 册的词表对拍与像素阈值不再约束新功能；
  parity harness 保留，身份从「平价门禁」转为「回归工具」。
- `CONTEXT.md` 词汇表继续有效（产品内术语单源）；新概念命名裁决以本册后续 ADR 增补。
- 05 册 §6 后票清单转为自有 backlog，按使用痛点涌现排序（W4+）。

## 2. D2 License

Apache-2.0：MIT 的宽松度 + 专利授权条款，dev 工具生态位主流。
落地 = W1：根 `LICENSE` 全文 + `package.json` license 字段对齐。

## 3. D3 名称

保留 pacman。npm 上 `pacman` 已被占（静态站点生成器），发布形态 =
`@xiechimon/pacman` scoped 包，`npx @xiechimon/pacman` 仍是一条命令。
若未来改名：品牌槽单源（02 §5.8）一次替换全仓生效，GitHub rename 有自动重定向。

## 4. D4 公开策略

仓自始 public，不转 private；门面未修好前不在任何渠道主动宣传。
「门面修好」的定义 = W1 全票落地。

## 5. D5 工作模式

仓库 owner 定方向、审 PR；施工走 agent 车道（worktree + PR 纪律不变，
`AGENTS.md` 继续约束所有车道与提交）。

## 6. D6 文档语言

`README.md` 英文主写（开源受众默认面）+ `README.zh.md` 中文副页互链；
`docs/spec/`、`docs/research/` 维持中文，不翻译。

## 7. D7 研究资产

`docs/research/` 的原站截图与全部 git 历史保持现状——不 scrub、不移出；
README 免责声明常驻。素材核账仅约束产品内资产（AppIcon / favicon / 品牌串 /
对外引用），按 `docs/spec/素材替换计划.md`（#44）逐项核。

## 8. D8 鉴权

- **可选 token 鉴权**：env 显式开启、默认关；形状细节（保护面边界、machine
  端点豁免清单、绕过路径枚举）归 W1 spec 钉死，实现先列绕过路径再写码。
- **启动护栏**：server 检测到 `0.0.0.0` 绑定且鉴权未启用 → 启动日志醒目 WARN。
- 完整账号体系不做（与轻量自托管定位冲突）。

## 9. D9 分波

| 波 | 内容 |
|---|---|
| W1 门面+鉴权 | LICENSE；README 英文重写 + 中文副页；repo description/topics 修复；issue/PR 模板；素材核账（AppIcon/favicon/品牌串）；可选 token 鉴权 + `0.0.0.0` WARN |
| W2 npm 首发 | web dist 预打包进包；`@xiechimon/pacman` publish 管线；版本 0.1.0；`npx` 一条命令实测 |
| W3 steer 中断 | building/review 态发消息——daemon 缝在位、词表有位，补 REST + web 面（复刻期确认的真实功能缺口） |
| W4+ | 05 册 §6 其余后票（OAuth 族扩展、授权页、服务端搜索、streamdown、API key 权限位弹窗等）按使用痛点涌现排序 |

## 10. Premortem 护栏

1. **原站权利主张**（概率低非零）→ W1 素材核账保证产品内零原站资产；免责声明常驻；
   W3 尽早建立分化证据。
2. **发布后无人问津、维护熄火**（开源最常见死法）→ 自用即第一用户；门面做到
   「看起来活着」；发布后定点社区发帖，不搞大水漫灌。
3. **可选 token 半成品反扩安全面** → W1 spec 钉死形状（默认关、豁免清单、
   绕过路径枚举先行），/tdd 先列失败方式再写码。
