- 验收对象三源：① r7 冻结基线（53 图 @1440×732 + icons.json 64 唯一，`docs/research/assets/r7/`）；② rN 研究正典记录的实测行为（r1/r2/r3/r5/r5b/r6/r7，后续 r8）；③ 02 册 canonical 词表与记录形状。
- **不对照实时官网**：像素与行为验收一律对照冻结批次；实时官网仅作漂移监测输入（漂移事实成立 → A6 重拍流程，不逐票追新）。

## 2. 像素平价层（定型规则）

**工具**（已建成，`parity/`，#53–#58 实跑验证）：

- 采集：`vite build --mode parity`（保 `?scenario=` 存活）+ `vite preview` 127.0.0.1:8390 + Playwright chromium，视口 1440×732 DPR1；注入 localStorage `tds-theme` / `tds.sidebar-collapsed`，`[data-parity-scroll]` 设 scrollLeft；等字体 + rAF 后截图。看板超宽 = 左右拼接两拍（r7 §0 方法）。
- 评分：ffmpeg `ssim` 逐对打分；产物 `<id>.png` + `.side-by-side.png` + `.blend.png`（50% 鬼影）+ `report.json` → `parity/output/`（gitignored）；任一行失败 exit 1。
- 定位：`parity/diff-regions.mjs` 24px 格亮度热图 + top-25 热格；文本回捞 `parity/match-text.mjs`。

**矩阵行契约**（`parity/matrix.mjs` 头部注释为权威）：`{id, route, scenario, theme, scrollLeft?, sidebarCollapsed?, baseline?, threshold?}`；baseline 指 r7（后续 r8）文件。

**阈值体系**：

| 档 | 值 | 规则 |
|---|---|---|
| 默认 | ssim ≥ 0.85 | 有基线行通用 |
| 单屏 override | 0.84 | 仅限跨平台字体栅格化噪声屏；条件 = 登记理由 + blend 人工核无结构差异（现行两例：`detail-confirm-light`、`detail-failed-light`） |
| smoke | 1.0 | 无基线行自比对，只验管线 |
| report-only | 0 | 出报告不门禁（现行：27b/28 展开态、`detail-building-dark`、#75 的 14 行长 CJK 折行面——折行点随渲染器字体栈漂移，blend 已核无结构差异，待捆绑 CJK 字体或分宿主基线后收紧） |

**门禁**：CI（ubuntu，Node 24 + ffmpeg + Playwright chromium）跑 `typecheck + lint + parity`，push main/`web/**`/`prototype/**` 与全 PR 触发；绿 = 合并前提。

**增量规则**：每张 web 实现票验收增量 = 矩阵加行（新屏/新态/双主题）；弹层票须含 open 态行；深色面随票覆盖。

**基线批次纪律（A6）**：r7 为现行唯一像素权威（r5/r6 位图已 git rm，DOM 表保留作几何旁证）。r8 补拍产物续编号（54+）落 `assets/r8/`，矩阵 baseline 逐行切换；若官网整体再漂移，重拍册级基线（r9…）并全矩阵切换，禁止两批次混对。

## 5. 通知 divergence 验收口径（A5，R1 终裁）

- in-app 层 **1:1**：SSE `notification` 事件 `plan_ready` / `build_review`（含定时轮）/ `chief_message`，事件形状与未读联动（`GET /api/teams/{id}/notifications` → `{unreadThreadIds}` + 徽标）照 02 §9.1；done/failed 无 in-app 事件照抄。
- 桌面层 **divergence**：页内 `new Notification()`（`document.hidden` 时弹）兑现「标签页切换到后台时，通过桌面通知提醒你」语义；不实现 Web Push/VAPID/sw push 投递。理由三条（#45 裁决记录）：① 浏览器 push 依赖 FCM 等宿主，大陆环境不可达，名义平价实际收不到；② 原站 push 订阅自身被服务端 400（r5 §7.3 实测），桌面弹出列在原站即 broken；③ SSE+页内 Notification 覆盖「页签后台提醒」主语义，浏览器全关场景超出 web-only 口径。
- sw.js 处理：字节级搬义务下 push handler 代码形状保留，服务端不产生 push 消息（死代码容忍，登记本册）。
- 桌面壳预留：原生通知路径形状保留（02 §9.1），不在 web-only 验收范围。
