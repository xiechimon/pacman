serve-live 对端实测（验收 #5 硬条款）
=====================================

拓扑
----
服务跑在 mea（WSL2，tailnet 名 wsl2-linux / 100.65.44.76），绑 HOST=0.0.0.0。
对端 = 用户那台 Mac，它自己也是 tailnet 节点 xmons-macbook-air / 100.125.21.46
（mea 上 ssh 别名 `mac` → HostName 100.125.21.46，实测 `ssh mac hostname` = xmonsMac-3574.local）。

实测一：对端 Mac → mea 的 tailnet 地址（--noproxy 绕本机 7890 代理）
-------------------------------------------------------------------
$ curl -s -m 10 --noproxy '*' -o /dev/null -w "%{http_code}\n" http://100.65.44.76:28115/
200
$ curl -s -m 10 --noproxy '*' -o /dev/null -w "%{http_code}\n" http://100.65.44.76:28115/api/auth/session
200
$ curl -s -m 10 --noproxy '*' -o /dev/null -w "%{http_code}\n" http://100.65.44.76:28115/app/resources/agents/nMoSPo8fUSQ5lH-PS69Or
200
（首次实测带时间：root=200  time=0.904226s）

实测二：mea 侧 ssh 别名 `mac` 可达性
------------------------------------
$ ssh -o BatchMode=yes mea 'ssh mac "hostname"'
xmonsMac-3574.local

结论
----
对端（用户那台 Mac）实测 200 ✓；该地址为通用地址（服务绑 0.0.0.0），
Windows 宿主（mea 的 localhost 转发）与 mea 本机 loopback 各走各的地址，未单独实测。
