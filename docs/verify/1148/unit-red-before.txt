## server 面（apps/server/test/machine-concurrency-chief.test.ts）

$ corepack pnpm --filter @pacman/server exec vitest run test/machine-concurrency-chief.test.ts

 Test Files  1 failed (1)
      Tests  7 failed | 2 passed (9)

红项（票面失败方式 → 断言）：
1. chief 饿死回归：满载 worker（cap 1、1 worker claimed）时 chief 步不被领
   —— claimStep 返回 null，pending chief 等到超时。断言「chief 立即被领」失败。
2. chief 占位回归：仅 chief 在跑（cap 1）→ worker 步不被领（chief 误占槽）。
3. 读面口径：runningSteps（me / machines 列表）数 chief（1 chief + 1 worker
   claimed → n=2 > N=1，n 恒 ≤ N 破约）；waitingFor.running 同误数。
4. FIFO 保序两向（闸开时 chief 更早 / worker 更早——现行行为零漂移对照）。
5. claim body maxWorkers：DB 3 / body 1、1 worker 在跑 → worker 仍被发
   （body 无消费面）；chief 照发不受 body 约束（无实现）。
6. body maxWorkers 0 → 400（schema 无校验，返 200）。
