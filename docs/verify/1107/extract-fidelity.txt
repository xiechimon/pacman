# Extraction fidelity (#1107)

Each .drawio.svg carries its full source, HTML-entity escaped, in the root
content attribute (drawio -e export). The source file on disk is the exact
unescape of that attribute; re-escaping the written file reproduces the
attribute bytes, so sha256(content attr) == sha256(re-escape(file)).
