# #791 对比度复测（base-ui-theme §5.1，P4/P5 面票）

方法：相对亮度公式（WCAG），sRGB 十六进制直算；tint 对先按 `color-mix`
配方在 sRGB 内插出实色再算。容差 ±0.02。渲染对实测另由
`accent-typo.spec.ts`（danger 对、主钮对逐主题拼比 ≥4.5）覆盖。

| 对 | 暗 | 亮 | 门 |
|---|---|---|---|
| 主钮字 | 8.81 | 5.41 | 4.5 |
| 正文 | 14.72 | 15.63 | 4.5 |
| 次级字 | 11.21 | 8.71 | 4.5 |
| muted | 8.22 | 6.54 | 4.5 |
| danger 字 | 4.92 | 5.02 | 4.5 |
| 选中对（tint 底） | 6.18 | 4.59 | 4.5 |
| 环（vs 纸面） | 5.58 | 3.27 | 3.0 |
| 环（vs 面板） | 5.19 | 3.02 | 3.0 |
| menu-icon 暗 | 3.44 | — | 3.0 |

结论：15/15 通过。亮侧环 3.27（纸面）/ 3.02（面板）按非文本 3:1 刚过——
面票注明口径（与 spec §2.1 末行一致：不通过则退 dim，本次通过不退）。
选中对亮侧 4.59 确认加深紫方案（F3：spot 原色做字只有 3.50）。
